`realgoal` (`index.ts`, `extensions/worker-entry.ts`, `src/`, `test/`) is written 100% in `effect@^4.1.2` using functional pipelines (`pipe` / `.pipe`, `Effect.Do`, `Effect.bind`, `Effect.flatMap`, `Effect.raceFirst`) — generators (`Effect.gen`, `function*`, `yield*`) are strictly forbidden across source and tests.

Key Effect v4 + Pi 1.5.0 integration notes:
- `Context.Service` keys use `.use(...)` and `.useSync((s) => s)` (not `.asEffect()`).
- In-memory tool `details` from `st0nie/realtasks` (`task_output`, `bash`, `task-notification`) carry explicit `undefined` values on optional keys (e.g. `{ exitCode: undefined }`), so `Schema.OptionFromOptionalNullOr(...)` must be used instead of `Schema.OptionFromOptionalKey(...)`.
- `ctx.executeTool(...)` in Pi 1.5.0 returns `AgentToolCallOutcome` (`{ toolCall, result: AgentToolResult, isError }`), so nested tool output lives on `outcome.result.content` and `outcome.result.details`.
- Verify changes with `bun run check` (`bunx tsc --noEmit && bun test`).
