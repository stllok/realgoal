Pi 1.5.0's `pi.getCommands()` delegates to a throwing action stub until the extension runtime is bound; calling it from the extension factory causes `Extension runtime not initialized. Action methods cannot be called during extension loading.` Realgoal's collision-aware command registration belongs in a guarded `session_start` handler in `src/commands/register-commands.ts`, after all extension factories load. Register commands once per extension runtime so repeated session starts don't identify Realgoal's own commands as collisions. Await collision memory updates rather than launching a floating promise. `test/extension-loading.test.ts` uses Pi's real factory loader and uninitialized runtime stubs to cover this lifecycle boundary.
