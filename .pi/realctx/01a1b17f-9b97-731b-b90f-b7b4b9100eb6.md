To keep agents from reverse-engineering Realgoal's source code (`~/.pi/agent/git/github.com/stllok/realgoal`) during `/goal` and `/plan` without bloating idle sessions:
1. All 6 tools in `src/tools/register-tools.ts` declare `promptSnippet` (`realgoal_control` also sets `promptGuidelines` forbidding source-code reads), and `targetPhase` uses an explicit 16-phase `Type.Union` with description.
2. `before_agent_start` in `src/lifecycle/register-hooks.ts` injects `Legal Next Phases` (via `getLegalNextPhases` from `src/domain/reducer.ts`), `Phase Contract` (`describePhaseContract`), and a pointer to the `realgoal` skill only while a workflow is active.
3. `skills/realgoal/SKILL.md` (exposed via `package.json` `pi.skills: ["./skills"]`) holds on-demand reference rules for `finalized.md` validation, `realgoal_todo` + `realgoal_finish(recordGoalLevelVerification: true)`, static HTML/SVG `realgoal_preview` constraints, and `realgoal_delegate`.
