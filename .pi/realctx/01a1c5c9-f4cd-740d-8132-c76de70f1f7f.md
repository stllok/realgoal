Realgoal workflows transition to `paused` only from:
1. Agent calling `realgoal_control(action: 'pause', reason: ...)` with a non-empty `reason` (`src/tools/register-tools.ts`).
2. User interrupt (`Escape` abort in `decideBeforeSettle` / `agent_settled`) or explicit user `/realgoal pause` / menu stop.
3. Session crash recovery in `session_start` (`src/lifecycle/register-hooks.ts`) when a previously `running` work item is in `process` or `implement` phase.

`tool_error` in `tool_execution_end`, `recordOperationFailure`, `maxNoProgressContinuations`, and `maxTotalTurns` do NOT auto-pause the workflow.
